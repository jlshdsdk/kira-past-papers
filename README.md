# Kira 考研数学真题切片集 · 自学站

《Kira·2027 考研数学真题切片集》题目录入与解析网站（个人学习用途）。

- 题目：按原书目录逐考点切片（上册 高等数学 考点 1–61；下册 线性代数 考点 1–25、概率论 考点 26–51）
- 题目以原书页面裁剪图呈现（含公式与图形），解析用 KaTeX 渲染
- 每道小题标注来源：【官方答案】/【网络权威解析】/【自解】，全部经过两遍独立重做校验（A/B 双验），不一致题目经仲裁修正
- 覆盖 1987–2026 年考研数学一/二/三真题

## 使用

直接浏览各考点页面：题目图片 → 动手做 → 展开「答案与详解」对照。

## 结构

- `index.html` 总导航与完成度统计
- `gs/chNN/` 高等数学考点页 · `xd/chNN/` 线性代数 · `gl/chNN/` 概率论（沿用原书连续编号）
- `assets/q/` 题目裁剪图 · `assets/css/site.css` 样式

数学公式渲染使用 KaTeX（CDN）。纯静态站点，无构建依赖。
